# Perubahan

## 0.5.0

- Tambah token cukup dengan ID transaksi. Tautkan akun Telegram sekali lewat `/tautkan`, lalu pilih transaksi dari daftar atau ketik ID-nya.
- Token garansi, hadiah referral, dan bonus admin ikut bisa diambil.
- Tes koneksi semua token, token bermasalah, atau token yang belum diuji, dengan pilihan model.
- Pengaturan reasoning per model: Auto, Low, Medium, High, Max.
- Konfigurasi siap salin untuk opencode, Hermes, pi, dan omp di menu Panduan.
- Batas input dan output tiap model diumumkan ke aplikasi, jadi aplikasi tidak perlu menebak.
